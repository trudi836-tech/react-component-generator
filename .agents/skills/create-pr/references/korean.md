# 한국어 PR 템플릿

PR 본문은 아래 구조를 사용한다. 대괄호 안의 안내문은 실제 정보로 바꾸고, 해당하지 않는 선택 섹션은 제거한다.

```markdown
## 변경 사항

- [사용자와 리뷰어가 이해할 수 있는 실제 변경 사항]

## 검증

- [실행한 명령과 결과]

## 참고 사항

- [리뷰어가 알아야 할 제약, 후속 작업 또는 호환성 영향]
```

UI 변경으로 스크린샷이 실제로 존재하면 `## 스크린샷` 섹션을 추가해 첨부하거나 링크한다. 연결된 이슈가 확인되었고 사용자가 연결을 요청한 경우에만 `Closes #번호`를 추가한다.
