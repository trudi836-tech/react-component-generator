# English PR template

Use the structure below for the PR body. Replace bracketed guidance with verified information and remove optional sections that do not apply.

```markdown
## Summary

- [A reviewer-facing description of the actual change]

## Validation

- [Command run and its result]

## Notes

- [Constraints, follow-up work, or compatibility impact reviewers should know]
```

For a UI change, add a `## Screenshots` section only when screenshots actually exist. Add `Closes #number` only when the linked issue is known and the user asked for it to be linked.
